# Changelog
Formato basado en Keep a Changelog; versionado SemVer.

## [0.1.0] - Semana 1
### Añadido
- Interfaz renovada (tema oscuro tipo vidrio), imagen de fondo, imagen PNG de personajes y efectos de sonido (Web Audio) con botón para silenciar.
- Esquema PostgreSQL, datos semilla y Docker Compose.
- API REST de incidentes: crear, consultar, filtrar, asignar, estados, bitácora y dashboard.
- Frontend React: formulario, listado con filtros, detalle y dashboard.
- Pruebas de integración (Jest + Supertest).
