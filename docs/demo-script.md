# Guion de la demostración final (≈10 min)

1. **Negocio (1 min):** problema y objetivo; mostrar Azure Boards (Epics → Features → Stories → Tasks, estados y responsables).
2. **Trazabilidad (2 min):** abrir un Work Item → rama → commits con `AB#` → PR con revisión → merge.
3. **Aplicación (2 min):** crear incidente, asignar técnico, recorrer estados, comentar, filtros y dashboard.
4. **Pipeline (2 min):** run exitoso, pruebas, cobertura, `npm audit`, artefacto; mostrar el run fallido con diagnóstico y corrección; agente autohospedado en el pool.
5. **GitHub Actions (30 s):** workflow ejecutado en un PR.
6. **Seguridad (30 s):** Variable Group con secretos protegidos, sin secretos en el repo.
7. **Release (1.5 min):** ambientes DEV/QA/PROD, aprobación, tag `v1.0.0`, release notes.
8. **Cierre:** deuda técnica resuelta (DT-01, DT-02) y lecciones aprendidas.
